# 报告与演示素材使用指南

| 报告/PPT部分 | 素材位置 | 写作注意 |
|---|---|---|
| 背景与相关工作 | REFERENCES.md | 区分实际使用与只调研的方法 |
| 算法流程 | 源码、EXPERIMENT_PROTOCOL.md | 清楚说明使用公开预训练模型 |
| 数据与硬件 | results/local500/environment.json、eval_manifest.json | 写真实样本量与显卡，不沿用Colab的T4 |
| 定量结果 | summary.csv或accuracy_summary.csv | 从文件读取，避免手抄旧结果 |
| 图表 | results/local500/figures/*.png / *.svg | PNG直接插图；SVG放大不失真 |
| 案例演示 | assets/与完整本地结果 | 展示成功也展示失败 |
| 分析与局限 | results/local500/RESULTS.md | 保留统计区间、评价边界 |
| AI使用分享 | AI_AGENT_LOG.md | 讲清问题发现、修复、验证过程 |

推荐答辩流程：先运行demo进行交互，再展示固定批量结果，最后回答指标含义与复现方法。首次演示前提前启动，让模型加载完成。离线演示前确认models/完整；图表和精选音频/图片不需要联网。
