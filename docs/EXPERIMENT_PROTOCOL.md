# 实验协议（在观察结果前确定）

日期：2026-10-22。只运行预训练推理，不训练或调整模型权重。随机种子42，按排序后的数据集元信息随机抽样。下载失败重试原样本，禁止以其他样本替换。所有方法使用同一清单。

视觉问答：VQAv2 val2014抽500题，10人人工答案。greedy(num_beams=1)、beam3(num_beams=3)、blank_image(均匀灰图、greedy)。最大20个新token，do_sample=False，batch_size=8，GPU FP16。每种设置用一个完整批次预热，不计入耗时。保存逐题答案，官方评测器计算整体、答案类别与问题类型得分。

按image_id聚类进行3000次配对bootstrap。greedy为参考，报告变化题数和差值区间。按类别与question_id确定性选前2个全错、2个全对案例，避免按戏剧性挑例。小于10题的问题类型不制作排序图。

## 复现与失败处理
模型锁定Hugging Face提交；保存数据清单SHA256、环境、源码哈希和参数。输出目录身份不匹配时拒绝续跑。下载文件校验大小/可读性；没有跳过失败项来抬高指标。每条结果写入后保存，断点续跑仅在配置相同且已有文件有效时启用。推理失败时保留日志和已完成输出。

本机浮点实现、GPU与库版本会影响数值，固定随机种子并不保证不同硬件逐字节一致。复现应同时比较配置、预测/音频与指标，不只比较最终均值。
